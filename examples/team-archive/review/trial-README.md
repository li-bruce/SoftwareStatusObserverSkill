# 资料柜 · 本地归档演练 v2

这是使用 business-observer candidate-8 的独立模拟开发演练。人员、审批、资料和存储均为本地合成数据。

打开操作台：<http://127.0.0.1:8824/>  
打开开发者图：<http://127.0.0.1:8824/graph>

需要 Python 3.11+、`requirements.txt` 中的 transitions；验证图还需要 Node。演练机器的解释器仅作为运行工具使用：

```powershell
$archivePython = 'C:\Users\Lvi_P\Documents\Work\CF\平台软著\SoftwareStatusObserverSkill\.venv\Scripts\python.exe'
& $archivePython -X utf8 -B validate.py
& $archivePython -X utf8 -B run.py --port 8824 --db data/v2.sqlite3 --delay 4
```

`validate.py` 是正常交付入口；会检查已验收的源码/模型同步、归属隔离、规则和历史事实，失败时返回非零。它不会自动接受新基线。`--candidate` 仅用于开发，页面会标明尚未验收。修改后的完整观测维护由 AI 按 `AGENTS.md` 执行，用户无需编辑同步材料。

先为当前操作人审批当前版本，再新建归档运行。每次运行选择 1 或 2 个名额；每项检查占一个。默认的 4 秒演练延时仅用于观察并行、等待和取消，可设为 0。无有效审批时等待；恢复审批后需点击对应运行的“继续”。取消只影响该次运行，已启动检查自然结束。正文出现区分大小写的 `SECRET:` 或标题/项目/编号缺失时，检查不能通过。

只认当前文件夹的直接负责人，审批须由另一审核员发出并匹配项目、操作人、资料及内容版本；任意一条当前有效即可，截止时刻本身已失效。内容修改生成新版本，旧运行不能提交。两项检查必须属于同次运行同一版本。最后提交在同一 SQLite 事务中重查资格，保留不可变快照并对资料/版本去重，不移动或删除原资料。

项目归档大小上限默认 8192 字节，只计正文 UTF-8 字节数，等于上限允许。操作台仅接受正整数，不替小数取整。上限变化不修改内容版本或审批，不影响已有快照。开始、继续、最终提交都读取当前项目配置。运行中超限时，已启动检查自然结束，未启动检查等待；条件恢复后手动继续，复用同次同版本已通过结果。

开发者图支持在同一画布逐层展开、搜索隐藏参数、读取实际输入/返回及审批候选、看资源和等待、查看对应加载源码。可拖动、固定、布局撤销、改显示名和备注；浏览器本地保存布局和标注，不改变业务。历史时刻只显示该帧已记录事实；缺失事件保持未知。旧构建运行保留状态，但不套用当前源码解释。

图的版本菜单可切换“第一版 · 已冻结”；首版使用其冻结模型、源码和运行记录。当前图顶部显示当前项目上限，节点上的历史判断保留当时实际值并标识已过期依据；旧运行不套用新源码。原节点身份、位置、固定状态、显示名称和备注保持在同一浏览器保存空间。

第二版证据在 `review/v2/`，新增节点和参数详见 `review/v2/node-changes.md`。首版证据和快照保留在 `review/v1/`；原始问题、工具失败、修复及候选材料保留在 `review/round-*`。这是 agent 按模拟用户需求执行的开发与浏览器演练，不是真人用户研究；测试覆盖有限场景，不代表所有线程交错或生产身份鉴权。未安装全局 hooks；绕过验证入口的外部编辑不会自动同步。

在装有 Python 与 Node 的其他目录中，复验入口为 `python -X utf8 -B validate.py`。验证脚本和 sync 命令使用当前解释器，不依赖上面的本机示例路径。`AGENTS.md` 仍指向这次演练的相邻 Skill 快照；转入其他仓库时需另行调整该指令路径并重新验收，不能当作已完成的外部发布。
