# Generated observation files

`behavior.json` and the UI files are generated by `tooling/build_graph.py`.
Editable UI source is in `integrations/bo_view/`. Runtime helpers are copied
from `skills/business-observer/scripts/`; `tools/check_package.py` checks equality.
PixiJS is vendored with its license. Rebuild, review and run the change checks
after changing a source. These files do not own business decisions.
