# VibeLens v0.7.1

Business Observer is now **VibeLens**: understand and debug AI-built software
through state graphs.

- Invoke `$vibelens` and install the complete `skills/vibelens` folder.
- Use [li-bruce/VibeLens](https://github.com/li-bruce/VibeLens) and the updated
  [bilingual introduction](https://li-bruce.github.io/VibeLens/).
- Migrate an existing installation explicitly with a retained backup and failure
  rollback. Existing VibeLens directories remain protected from replacement.
- Runtime modules, schema/protocol identities and personal layout keys retain
  their compatibility. The prior release and its original evidence stay available.

```bash
git clone --branch v0.7.1 https://github.com/li-bruce/VibeLens.git
cd VibeLens
python tools/install_skill.py --project /path/to/your-project
```

For a project already using the old name, add `--migrate-legacy` to the install
command. Read the [migration guide](https://github.com/li-bruce/VibeLens/blob/main/docs/rename-vibelens.md)
and [rename acceptance](https://github.com/li-bruce/VibeLens/blob/main/docs/review/vibelens-rename/README.md).
The attached ZIP contains the complete installable VibeLens Skill. The independent
application trials remain in the [v0.7.0 evidence](https://github.com/li-bruce/VibeLens/tree/v0.7.0/docs/review/release-v0.7.0).
