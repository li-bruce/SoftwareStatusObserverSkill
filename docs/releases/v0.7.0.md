# Business Observer v0.7.0

Follow application behavior from business decisions to selected runtime values,
database operations and optional source relationships in one developer graph.

## What changed

- **Explore code when needed.** Select a region and enable Local code, or open
  Code structure for the indexed project. Files, classes, functions, parameters,
  calls, imports and inheritance have distinct types. Source edits refresh the
  enabled index; unresolved calls and display limits remain visible.
- **See data structure and use.** Database structure and data-operation views
  connect models, stores, queries, selected transformations and transaction
  outcomes. Python and Node adapters cover tested SQLite, PostgreSQL, MongoDB,
  Redis and Neo4j paths. Storage selection and capture setup are part of the
  Skill's development guidance.
- **Keep the view across iterations.** Stable identities preserve positions,
  filters, expansion, annotations and custom views. The current recording list
  contains only the current graph version. All elements distinguishes visible,
  folded and filtered content. Recording health separates actual capture gaps
  from normal live-history expiry.
- **Check each coding batch from the graph.** Changed nodes, neighboring
  consumers, shared helpers and state/data dependencies guide case selection.
  Mapping, state rules, business expectations and project checks still report
  separately. Required observations and independent expectations remain strict.
- **Clearer ownership.** Shared data-evidence validation removes conflicting
  interpretations. Request-scoped sessions let ingestion continue during a slow
  source request and safely retire old builds. The source guide documents module
  responsibilities and the paths taken by edits, events and view interactions.
- **Updated introduction.** The bilingual product page includes data and source
  perspectives; a separate interactive walkthrough shows a sample use session.

## Acceptance and known boundaries

The [ordered work table](https://github.com/li-bruce/SoftwareStatusObserverSkill/blob/main/docs/development/code-vis-release.md) records branch
commits and publication checks. The [assessment](https://github.com/li-bruce/SoftwareStatusObserverSkill/blob/v0.7.0/docs/assessment/2026-10-24/README.md)
records reproduced defects, repairs, regression results and remaining limits.
The [independent trial](https://github.com/li-bruce/SoftwareStatusObserverSkill/blob/v0.7.0/docs/review/release-v0.7.0/README.md) preserves dialogue,
graph confirmation, application versions, screenshots and failures followed by
retests. Its user role is simulated; execution, SQL effects and browser actions
are real.

Explore the [bilingual product introduction](https://li-bruce.github.io/SoftwareStatusObserverSkill/)
or its separate interactive walkthrough.

Static source relations describe what the configured parsers can establish.
They are not a complete trace of dynamic dispatch. Rendering has explicit
budgets; the JSON index can be exported in full. Generic API-to-client mapping,
automatic column lineage, arbitrary ORM support, database-internal execution
plans and a production load baseline remain future work.

## Install and try

```bash
git clone --branch v0.7.0 https://github.com/li-bruce/SoftwareStatusObserverSkill.git
cd SoftwareStatusObserverSkill
python tools/install_skill.py --project /path/to/your-project
```

The installer preserves an existing Skill directory and reports that it already
exists. Review local changes before replacing an older installation. Installing
the Skill and upgrading an application's managed runtime are separate actions;
use the documented upgrade procedure for an existing observed project.

Start a new Codex conversation in the target project:

> Use $business-observer for this project. Show the initial business graph in
> this conversation and give me its Web address. Ask the necessary questions to
> confirm my intent, then keep code, observations and graph checks synchronized.

Choose drive or observe when asked. You can request Local code later without
turning the initial business graph into a complete source diagram.
