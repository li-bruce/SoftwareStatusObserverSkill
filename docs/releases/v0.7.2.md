# VibeLens v0.7.2

The graph viewer now keeps the canvas in focus, with a compact toolbar, visible-type
legend and node/edge context menus.

- English is the default. The coding conversation sets the initial language; a manual
  language choice takes precedence and survives reloads.
- Recording, stop, clear and replay use accessible SVG icons with translated tooltips.
  Clear removes only the selected stopped recording. Loading another recording and
  active recording both prevent accidental clearing.
- Right-click or Shift+F10 opens actions for nodes and edges. Notes, core markers,
  pinning, source inspection, group movement and saved layouts remain available.
- Conversation focus highlights the graph directly. The discussion bar is removed;
  click empty canvas or press Escape to dismiss focus. Expired scope clears silently.
  View changes stop old animations before graph objects are released.
- The bilingual Pages introduction adds a five-step viewer tour with pause, next-step
  controls and reduced-motion support.

The state definition, business execution and verification requirements remain in
place. Existing example projects use the same source inventory and acceptance gates.
See [acceptance evidence](https://github.com/li-bruce/VibeLens/blob/main/docs/review/viewer-ui/README.md)
and [usage](https://github.com/li-bruce/VibeLens/blob/main/docs/usage.en.md).

```bash
git clone --branch v0.7.2 https://github.com/li-bruce/VibeLens.git
cd VibeLens
python tools/install_skill.py --project /path/to/your-project
```

Install the complete `skills/vibelens` directory and start a new conversation with
`$vibelens`. Existing installations are protected from overwrite; retain a backup
before replacing one. Existing project runtime copies require a managed upgrade.
