# v0.6.0 — Native adapters, checked iterations, and a bilingual introduction

Business Observer now separates shared Python graph services from native application adapters. Python, Node.js, React, and Vue projects exchange versioned JSON source and runtime facts. Developers choose **drive** or **observe** at adoption; both retain source mapping, identifiable probes, synchronization, and acceptance checks.

## Changes

- Split graph, workflow, observation, Web, delivery, and language adapters into explicit modules. Retire obsolete viewers and schemas while retaining deliberate migration entrypoints.
- Show the initial business graph in conversation and provide its verified Web address. Clarify the user's intent without inventing business requirements. Keep confirmation in conversation.
- Inventory source independently of existing nodes, including login, notifications, queries, and frontend handlers. Maintain the graph and capture contracts during each coding iteration.
- Exclude observer polling, reporting, preferences, and recording controls from business events. Preserve relevant source inventory and strict observer-isolation checks.
- Repair portable upgrade metadata, chained-call source identities, design-model loading, optional state labels, and replay wording. Keep real business states distinct from activity labels and raw values.
- Use English for maintained source, Skill instructions, and default documentation. Provide Chinese documentation and persistent English/Chinese viewer preferences without rewriting original labels or evidence.
- Publish an illustrated [English introduction](https://li-bruce.github.io/SoftwareStatusObserverSkill/?lang=en) and [Chinese introduction](https://li-bruce.github.io/SoftwareStatusObserverSkill/?lang=zh-CN) on GitHub Pages. Deploy only `docs/site`; the product page's replay is an illustration, not a live collector.
- Preserve exact shared package-marker bytes through Git checkout. Check public documentation independently of paths on the maintainer's computer; retain original transcripts with hash-bound historical references and verified archive members.
- Read JavaScript parser input asynchronously to EOF, preserving fragmented UTF-8 and rejecting incomplete JSON. Use shipped regression fixtures on clean clones and verify archive acceptance against committed LF bytes.
- Update the runnable multilingual example to Vue 3.5.44 and Vite 7.3.7. The refreshed lockfile reports zero known npm advisories on the publication date, and all 18 native cases pass. This addresses the reported [Vite path restrictions](https://github.com/vitejs/vite/security/advisories/GHSA-fx2h-pf6j-xcff) and [Vue server-renderer advisory](https://github.com/vuejs/core/security/advisories/GHSA-g2v6-rqmx-r4w6); a dependency audit is not proof of application security.

## Install for a real trial

Use a new or existing project directory without an installed `business-observer` folder:

```bash
git clone https://github.com/li-bruce/SoftwareStatusObserverSkill.git
cd SoftwareStatusObserverSkill
python tools/install_skill.py --project /absolute/path/to/your-project
```

To reproduce this release instead of following `main`, run `git checkout v0.6.0` before installation. The installer copies the complete Skill to `.agents/skills/business-observer` and refuses to overwrite an existing installation. Review and back up local changes before replacing an older copy. Installing the Skill does not itself upgrade runtime files already copied into an application.

Open a new conversation in the target project and use `$business-observer`. Describe the feature, choose drive or observe, inspect the initial diagram and Web link, then confirm or correct the graph. [Complete usage instructions](../usage.en.md) explain dependencies, project integration, and upgrades.

## Boundaries

The native `bo.fsm/1` executors implement a validated flat subset. Full Python examples also cover concurrency, waiting, resources, joins, and recovery; complex native engines require an explicit adapter. Exact whole-program dynamic call analysis, generic database schema/lineage adapters, performance baselines, and business execution by editing the graph remain outside this release.
