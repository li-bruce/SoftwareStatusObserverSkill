# 功能与验收对应

本表逐项对应本地评估和开发方案。测试只支持其明确范围，不把有限场景等同于全程序证明。对话试用的需求方由 AI 模拟，程序、数据库、工具命令和浏览器操作实际执行。

## 代码问题

| 评估项 | 本轮落实 | 证据 |
|---|---|---|
| F1 协议分散 | 共同图/类型/状态/活动校验；简化模型明确区分协议 | `tools/test_refactor.py` 声明入口和非法配置反例 |
| F2 层级迁移误报 | 按真实父子关系匹配与条件优先级核对 | 与 HierarchicalMachine 真实迁移比较 |
| F3 空检查漏检 | 非空模式/断言、必需探针/命令保护 | 空配置及弱化检查反例 |
| F4 源变化未闭合 | 源码范围、维护任务、符号分类、统一收尾 | 新入口漏登记失败；watch 登记/验收更新与编辑中恢复 |
| F5 无界历史 | 事件数量/时间、轮换日志、直接订阅录制 | 保留上限和录制测试；增量 API、性能基线延期 |
| F6 领域耦合 | 字段白名单和语义标签由项目配置 | 权限筛选不猜名称；异领域对话程序 |
| F7 双实例来源 | 执行迁移，查询/记录/导出读同一真实快照 | 实际 SQLite 对照、等待运行与导出一致 |
| F8 当前摘要残留 | 当前图改为已确认含义，历史来源保留 | 模型源、discovery 与生成图复核 |
| F9 回归缺口 | 两种方式、独立模块、迁移、配置、录制进入统一入口 | `tools/verify.py`，独立对话试用 |
| F10 类型混同 | 类型敏感枚举和数值校验 | True/1、非有限数值反例 |
| 结构与密集职责 | 同步检查拆分；绘制/对象释放、存储、轮询独立 | [结构说明](architecture.md)与实际模块 |
| 复制与迁移 | 升级清单、冲突拒绝、失败回滚、兼容委托 | 升级及导入对象身份测试 |
| 源码位置迁移 | 显式一对一移动，保留图节点身份、探针和原白盒约束 | 三项迁移反例；独立项目 22 处实际迁移 |

## 核心验收 M01–M15

| 编号 | 实际检查 | 结果来源 |
|---|---|---|
| M01 完整替换 | 保留旧执行器与旧服务，比较状态、活动、资源、停止/恢复、实际效果 | `test_workflow_migration.py`；30 个旧新真实服务场景 |
| M02 同一声明 | 缺目标、缺条件、父子循环、类型、活动资源声明共用校验 | `test_refactor.py`、`test_stategraph_module.py` |
| M03 同一实例 | 同一快照投影与导出完全相同；查询多个尝试，未授权等待也存在 | 两示例 mapping witnesses；浏览器运行/导出检查 |
| M04 新增实现 | 无图节点的新文件仍被发现；只加 watch 仍拒绝；移除绑定失效 | 源范围及 gate 反例 |
| M05 核心值 | 实际存储独立读取，对照实例；白盒检查输入、结果、调用及构建身份 | 两示例观测命令、whitebox 测试；独立试用改错 |
| M06 决策路径 | 授权、版本、等待、提交实际结果；短路未求值不补造 | 原有正反例和历史回放测试 |
| M07 层级/并发 | 父级迁移、并行合法活动集合、内部状态；折叠不丢事实 | 层级反例、执行器测试、浏览器下钻 |
| M08 资源/身份 | 单名额等待、多名额实际重叠、归还、旧新运行隔离 | 真实场景、执行约束、旧新服务比较 |
| M09 检查不能空转 | 空模式、零断言、缺探针/命令、空范围、关闭分类/实际值对照 | 配置反例和 watch 实际进程测试 |
| M10 如实显示 bug | 业务违规仍保留真实值；映射与业务分别报告，错误投影失败 | 非法配置保留、分项报告反例；独立试用改错 |
| M11 两种开发方式 | 默认引导、明确拒绝仍维护；项目指令供下次接续 | 双方式示例、独立对话及迭代记录；不宣称宿主自动唤醒 |
| M12 观测隔离 | on/off/fault 效果一致；核心 ZIP 实际启动，不加载观测包 | 完整回归两个核心包 |
| M13 保留边界 | 数量/时间/日志容量、缺口、UI 淘汰不丢主动录制事件 | `test_recording.py` 与保留策略反例 |
| M14 个人配置 | 重载、服务重启、换端口、新浏览器、明确 ID 迁移、冲突/写失败 | UI 两轮、JS ID 迁移、Preferences 故障测试 |
| M15 跨领域 | 配置字段、规则标签；打印任务中尺寸/材料/机器等值 | 公共字段测试及独立对话项目 |

## 可见功能

| 功能 | 验证方式 |
|---|---|
| 主动提问、部分回答、修订、局部图 | requirements_dialogue/clarification 回归；独立会话逐轮记录 |
| 业务、函数、参数、状态、规则在同一图 | 模型/图投影测试；真实初始图、下钻与源码截图 |
| 高层起步、圆形展开、同类型填色、上层接圈 | 布局/投影测试；真实整组拖动和截图 |
| 共享节点引用、原身份不重复计数 | `test_recorded_views.mjs`、`test_graph_layout.mjs` |
| 节点、边、圈、层级筛选和十种预设 | JS 组合筛选检查；真实预设切换、自定义视图保存 |
| 选中关联高亮、搜索隐藏节点、源码定位 | 真实鼠标选择、搜索、下钻与源码面板 |
| 拖动、固定、算法布局、撤销、折叠后恢复 | 布局测试；整组拖动、三算法、反复展开/收起 |
| 别名、批注、核心标记与跨端口恢复 | 真实保存及新浏览器读取项目文件 |
| 全部/局部采集、开始/结束、值变化、按视图回放 | 记录/历史测试；真实业务操作与回放截图 |
| 信息传递动画的类型、依据和缺口 | replay-steps/recording 测试；不能把静态边当已执行 |
| 类、方法、运行/调用实例身份 | AST、白盒及事件身份测试；不提供全对象堆视图 |
| ReBAC 规则、关系事实和求值区分 | 授权正反例及规则字段；通用引擎适配未实现，不列为通过 |
| 完整图、源码范围、录制与选定项目文件导出 | 导出一致性、focus/bundle 与核心包实际运行 |
| 安装、运行库升级、旧路径兼容 | 安装回归、版本散列/回滚测试、真实新项目使用 |

最后一次结果以同目录的 `checks/release7-regression.log`、`ui-final-result.json`、`ui-resume-result.json` 与 [独立对话最终记录](dialogue-trial/round-04/stage.json)为准。旧 `ui-result.json` 是绘图模块拆分前的回归，保留用于追溯，不冒充最终文件的截图。

独立对话的两次已验收阶段分别保存：公共接入阶段 48 次场景/24 项浏览器检查；维护与普通函数迭代阶段 69 次场景/29 项浏览器检查。首次简化集成的通过报告被否定，另存 `deviation-01`。最终源码包在主会话重新解压运行门禁与项目测试通过；覆盖边界仍以具体场景和源码范围为准。
