# 操作记录、分析视图与共享节点

本轮面向开发者调试：从实际操作中保存一段执行，再从图中回看状态、参数和关系。图的筛选、拖动、标注和回放不会执行归档命令。

## 使用

1. 打开 [运行图](http://localhost:8824/graph)，点击“开始记录”。
2. 在“操作台”中审批、发起运行或执行其他操作。记录由本地服务保存，切换标签页不停止记录。
3. 点击“结束记录”。用播放/暂停、前后事件、进度条或事件列表回看；“定位事件”展开对应节点。“导出记录”保存 JSON。
4. “分析视图”选择业务流、状态机、函数与参数、权限判断、并发与资源、数据依赖、实际运行、等待与异常或共享关系。
5. 在“筛选”中组合节点、连线、圈、层级、范围和文字，填写名称后保存自定义视图。

圈内空白拖动整组，圈外空白拖动画布。展开圈沿用原节点类型色。共享入口有 ↗ 标记，与原节点共用值、源码和标注；收起一个分组不会收起另一个分组中的原节点。

“图例说明”解释类型、右下运行角标、展开数量、固定蓝点和备注标记。节点图形与图例共用几何定义，连线图例也使用实际线型与箭头定义。

## 方案选择

采用一个主要层级和可定位的共享入口。没有把两个圆的偶然重叠当作共享证据。这样保留一个真实节点身份，各分组仍可独立展开和拖动。

比较了 [Bubble Sets](https://vialab.science.uoit.ca/wp-content/publication_media/pdf/col2009c.pdf)、[LineSets](https://www.microsoft.com/en-us/research/publication/design-study-of-linesets-a-novel-set-visualization-technique/)、[KelpFusion](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/12/kelpfusion_tvcg2013.pdf) 和 [UpSet](https://upset.app/)。区域、连接线与交集矩阵各有适用场景；这里按圆形展开和源码定位的需求作取舍，没有进行真人对比实验。

接入协议和验证要求见 [Skill 参考](https://github.com/li-bruce/VibeLens/blob/v0.7.0/skills/business-observer/references/recorded-analysis.md)。

## 验证材料

- [业务与项目检查](verification.json)：交付示例、资料归档示例、当前独立项目的正常检查结果。
- [浏览器操作](browser-checks.json)：圈内拖动、圈外平移、共享折叠、视图保存、回放状态和传递动画。
- [真实记录与源码核对](recording-checks.json)：区间序号、运行身份、记录大小、源码哈希，以及旧资料和归档快照保留情况。
- [回放截图](replay.png)、[共享分组截图](shared.png)、[图例截图](legend.png)。

自动检查包括开始/结束边界、空记录、重复开始、进程更换、漏采、写盘失败、事件上限、旧记录读取和缓存上限；图检查包含深层状态筛选、共享身份、精确历史帧及有类型依据的连线动画。既有业务、审批、参数版本、并发、等待恢复和源码隔离检查继续执行。

浏览器发现并修正了以下问题：

- 状态机筛选曾把共享状态的入口提升为额外根节点；现在只在对应分组中显示入口。
- 选择回放事件曾自动退出当前分析视图；现在保持视图，显式点击“定位事件”时才展开定位。
- 低缩放下角标和名称难读；小图保留名称与一条关键状态，角标设最小显示尺寸。
- 回放工具栏和底部图例挤占画布；回放隐藏无关的运行选择项，适应画布时预留图例位置。
- 连线动画按事件依赖的类型匹配，不能将判断依赖当作传值或调用。
- 回放期间恢复连接后，连接提示仍可能停留在旧错误；现在每次成功连接都会更新提示。

实际操作保存了两段记录，共 271 个核心探针事件、5 个操作标记，覆盖三次运行。其中一段先以两个名额并发检查，再以一个名额执行；回放已核对各次运行的身份、名额和等待状态。两个区间内的事件序号连续，原资料、已有归档和之前的十次运行保持不变。更早记录绑定的旧源码在更新页面后仍可读取。

## 范围

记录覆盖已接入的核心探针和本地服务操作，不能捕获未埋点的普通函数、任意变量或外部系统。回放不会重新执行程序，未知帧不会借用结束状态。保存失败、事件缺失或进程中断会标明缺口。

记录放在示例项目的 `data/recordings`（交付示例为 `scratch/recordings`）；导出包含选定参数和对应源码，分享前按项目数据范围审查。拖动布局、名称、备注和自定义视图保存在当前浏览器的同一网站地址，尚无跨设备同步。

本轮验证是合成程序的自动检查和有限浏览器操作；没有据此声称所有设备、大规模图或真人使用均已验证。
